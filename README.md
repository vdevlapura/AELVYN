# Aelvyn website

Source for [aelvyn.com](https://aelvyn.com): a static site (HTML, CSS, a little JavaScript), no build step.

| File | Purpose |
|---|---|
| `index.html` | Home page |
| `privacy.html`, `terms.html` | Legal pages |
| `404.html` | Not-found page |
| `styles.css`, `script.js` | Styles and the early-access form |
| `assets/` | Logo, favicon, social preview image |
| `brand/` | Logo and LinkedIn images (PNG) |
| `robots.txt`, `sitemap.xml` | Search engine files |

To preview locally, open `index.html` in a browser.
